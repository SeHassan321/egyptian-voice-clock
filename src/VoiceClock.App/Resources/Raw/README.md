# Default voice

Put `voicepack.zip` in this folder to ship a default voice inside the app.

Create it on the phone: Setup → "ابعت الصوت كامل (عشان ينزل مع التطبيق)". The file is already
named `voicepack.zip`. Commit it here (or upload it to this folder on GitHub) and build again.

This README and `.gitkeep` are excluded from the app package (see VoiceClock.App.csproj).
